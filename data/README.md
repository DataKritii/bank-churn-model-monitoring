# Data

`Churn_Modelling.csv` is the *Churn Modelling* dataset (0.7 MB).

- Source: Kaggle, https://www.kaggle.com/datasets/shrutimechlearn/churn-modelling (a widely used copy of the same file is on GitHub, which the notebook downloads from if the file is missing).
- 10,000 customers of a European retail bank (France, Germany, Spain) × 14 columns; `Exited` = 1 if the customer left.
- No dates are included; amounts are treated as euros.
